A portfolio-ready restaurant operations dashboard designed to showcase a real product experience without requiring login, database, or payment setup.

## What this project shows

This project demonstrates a polished restaurant management interface with:

- live kitchen order tracking
- reservation and table workflow
- customer and guest management
- menu management
- QR-based dine-in menu experience
- marketing and campaign sections
- AI-style insights panel

## What changed in this version

- simplified the project into a clean product showcase
- removed Supabase and Stripe dependencies for easier deployment
- removed login/auth flow from the public-facing demo
- kept the experience focused on UI, product storytelling, and feature visibility
- made it suitable for a live portfolio or project page

## Tech stack

- Next.js
- React
- TypeScript
- Lucide icons
- Recharts
- Vercel deployment

## How to run locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Notes

This version is intentionally kept lightweight and deployment-friendly so it can be shown live as a project demo without requiring external backend services.
