## Project Overview

MasalaCraft is a modern restaurant operations platform designed to help small and mid-sized food businesses manage bookings, customer relationships, live kitchen operations, menu updates, and marketing campaigns from a single dashboard.

This project was built as a portfolio-ready SaaS product to showcase end-to-end product thinking, UI/UX design, dashboard architecture, and full-stack implementation using Next.js and Supabase.

## Why This Project?

The restaurant industry needs a system that does more than take orders. Operators need to:

- track guest preferences and repeat customers
- manage reservations and waitlists efficiently
- monitor kitchen performance in real time
- refresh menus without spreadsheet chaos
- run targeted marketing campaigns through WhatsApp and digital channels
- improve decision-making using AI-powered operational insights

MasalaCraft brings these capabilities together in a modern, founder-friendly interface.

## Core Features

- Executive dashboard with performance overview
- Customer directory with guest profile data
- Reservation management and booking workflow
- Live kitchen order tracking with status updates
- Menu management and stock/availability controls
- QR-based dine-in menu ordering experience
- WhatsApp campaign center for restaurant marketing
- AI insights panel for operational recommendations
- Settings panel for branding and business configuration

## Tech Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind-inspired component system and custom design tokens
- State/Data: React state management, Supabase integration
- Analytics: Recharts dashboards
- Payments: Stripe-ready billing setup
- Auth: Supabase-ready authentication flow
- Deploy: Vercel-ready production setup

## Product Modules

### 1. Executive Hub
A high-level business overview for restaurant managers to view current performance, order throughput, bookings, and key operational KPIs.

### 2. Live Kitchen (KDS)
Real-time kitchen order tracking with prep progress and order status updates, designed to keep service fast and organized.

### 3. Guest Management
Customer profiles, visit history, dietary tags, and restaurant engagement data for personalized service.

### 4. Reservation System
Bookings, seating flow, and reservation status management for smoother front-of-house operations.

### 5. Marketing Center
Campaign-ready workflows for restaurant promotions, festive outreach, and digital engagement channels.

### 6. QR Menu Experience
A guest-facing ordering system that allows customers to browse the menu and place orders directly from their phone.

### 7. AI Insights Panel
Decision-support tools that summarize customer trends, behavioral insights, and operational recommendations.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables:
   ```bash
   cp .env.example .env.local
   ```
4. Start the app:
   ```bash
   npm run dev
   ```
5. Open: `http://localhost:3000`

## Deployment

The app is structured for Vercel deployment and can be published with environment variables connected to Supabase and Stripe.
